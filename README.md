# VoltDash — Distribuição

Arquivos públicos de distribuição do VoltDash (head unit GWM/Haval):

- `apps.json` — catálogo da aba "Instalar Apps".
- APKs do app são publicados via Releases deste repositório.

Os temas do cluster são distribuídos dentro do próprio aplicativo.

O código-fonte do VoltDash é privado. Este repositório contém apenas artefatos
de distribuição.
